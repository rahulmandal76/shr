# EXERGIE'23 - College Tech Fest - README File

Exergie 2026 is the official college fest website developed to showcase and manage all events conducted during the fest. The platform provides detailed event information, schedules, registration options, and an interactive user interface to enhance the overall fest experience. Built using modern web technologies, the website focuses on responsive design, smooth navigation, and an engaging UI to deliver a seamless experience across all devices.
